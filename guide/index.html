XO 트레이닝

사용 설명서

트레이너 한 명이 로그인해 회원별 운동을 기록하고 서명을 받는 앱입니다. 아이디는 가입한 이메일이며, 인터넷 연결이 필요합니다.

1. 시작하기

  1. 가입하기에서 이메일과 비밀번호(8자 이상)를 입력합니다.
  2. 메일의 확인 링크를 누르고 앱에서 계속하기를 누릅니다.

2. 회원 등록

  1. 회원 탭 → 회원 추가
  2. 이름을 입력합니다. 메모와 총 수업 횟수는 선택입니다.
  3. 개인정보 동의를 체크하고 저장합니다.

3. 운동 기록

  1. 회원 상세에서 운동 시작을 누릅니다.
  2. 종목 추가에서 종목을 고릅니다. 부위 버튼이나 검색을 쓰고, 없으면 새로 만듭니다. 몸무게 운동은 맨몸 운동을 체크합니다.
  3. 무게(kg)와 횟수를 입력하고 세트 추가를 누릅니다.
  4. 세트의 연필 아이콘은 수정, 휴지통 아이콘은 삭제입니다.

4. 완료와 서명

  1. 오른쪽 위 완료를 누릅니다.
  2. 회원이 화면에 손가락으로 서명합니다.
  3. 서명하고 완료를 누릅니다. 완료 뒤에는 서명을 고칠 수 없습니다.

5. 기록 확인

  • 기록 탭: 진행 중인 운동과 최근 완료된 운동
  • 회원 상세: 월별 수업 횟수, 볼륨, 종목별 PR, 남은 수업

비밀번호를 잊었을 때

로그인 화면의 비밀번호를 잊으셨나요?에서 이메일을 입력하고, 메일로 받은 인증 코드와 새 비밀번호를 입력합니다.
